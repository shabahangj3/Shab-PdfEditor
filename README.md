# README — Shab PDF Editor

## What the Project Does

Shab PDF Editor is a modern Windows desktop toolkit for editing, converting, organizing, protecting and inspecting PDF documents. Each workflow is available in a dedicated tab so common PDF tasks can be completed without switching between several applications.

The application supports English and Persian, remembers the selected language, provides input and output previews, and uses the same native multi-size icon in the executable, title bar, Taskbar and Alt+Tab.

---

## Key Features Include

* Merge PDF files with drag-and-drop and page-order control
* Convert PDF pages to PNG or JPEG with DPI and quality controls
* Convert ordered images into one PDF or separate PDF files
* Remove, extract, move and rotate selected pages
* Split every page or custom page groups into separate files
* Apply image or PDF watermarks with opacity, scale, position and page-range controls
* Add header/footer text and automatic page numbers
* Inspect, edit or clean document and page-level metadata
* Extract embedded images, including images inside Form XObjects
* Structurally optimize PDF files and report the actual size change
* Add blank space to an existing page edge without adding a new page
* Crop margins and resize pages with a live before/after preview
* Protect PDFs with AES encryption and configurable permissions
* Remove a known password from authorized PDF files
* Preview selected input files and generated output files
* Switch the complete interface between English and Persian
* Check GitHub Releases automatically at startup or manually from the header

---

## Why the Project Is Useful

Shab PDF Editor brings frequently used PDF operations into one consistent interface. It is useful for office work, document archiving, preparing forms, publishing, scanning workflows and routine file cleanup. Clear validation, progress reporting and output controls help reduce accidental overwrites and make the result easy to find and review.

## How Users Can Get Started with the Project

### Requirements

* Windows operating system (x64)
* .NET 8 Desktop Runtime

### Installation

1. Download the latest ZIP package from the GitHub Releases page.
2. Extract all files from the archive.
3. Open the `publish-win-x64` folder.
4. Run `ShabPdfEditor.exe`.

### Basic Usage

1. Launch **Shab PDF Editor**.
2. Select the required tool from the sidebar.
3. Choose one or more input files.
4. Use **Preview** to review the selected input.
5. Configure the options and output location.
6. Run the operation and review the generated file in the output panel.

## Advanced Features

### Header and Footer

Add custom text or automatic page numbers to the top or bottom of selected pages. For Persian, Arabic and other Unicode text, select a suitable TTF or OTF font.

### Crop and Resize

Crop page margins or resize pages while comparing bounded live previews of the original and resulting PDF.

### Security

Apply AES-256 or AES-128 encryption, control document permissions, or remove a password when the current password is known and the user is authorized to modify the file.

### Metadata Editor and Cleaner

View and edit standard document information, clean metadata, and optionally process page-level XMP metadata.

### Spacer

Extend an edge of selected existing pages and keep the added space on those same pages; this operation does not append blank pages.

### Automatic Update Checking

The application compares its version with GitHub Releases and opens the official release page only after confirmation. It never installs an update silently.
